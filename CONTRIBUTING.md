# Contributing

Please open an issue describing the reproducible problem or small enhancement before substantial changes. Use focused PRs, tests, and descriptive commit messages. By contributing, you agree to the MIT license of this repository.

## Local tests

    python -m pip install -e .
    python -m unittest discover -s tests -v

Never submit personal data, API keys or documents you are not permitted to redistribute. Policy data needs an original URL, date, publisher, and clear attribution. Maintainers review contributions for correctness and real user value; low-effort or autogenerated PR spam is not accepted.
